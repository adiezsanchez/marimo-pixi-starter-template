# marimo + pixi Starter Template

A minimal starter for [marimo](https://marimo.io) notebooks using [pixi](https://github.com/prefix-dev/pixi) for environment management.

## Prerequisites

- [pixi](https://github.com/prefix-dev/pixi) installed

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/yourusername/marimo-pixi-starter-template
   cd marimo-pixi-starter-template
   ```

2. Open the notebook in the marimo editor:

   ```bash
   pixi run edit
   ```

## Project Structure

```
├── src/
│   └── app.py        # Sample marimo notebook
├── pyproject.toml    # Project + pixi configuration
└── pixi.lock         # Dependency lock file
```
